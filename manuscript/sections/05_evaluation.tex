\subsection{Geometric Envelope and Docking}
The $41^3$ grid contains 68,921 wrist configurations. The shoulder-to-wrist distance is bounded by the link sum, $L_1+L_2=0.200$\,m. The sampled wrist height spans $-0.0316$ to $0.3549$\,m in the base frame. Of the samples, 2,747 lie below the modeled $z=0$ ground plane and 66,174 lie on or above it. These counts are joint-grid counts, not Cartesian workspace volumes; an above-ground sample may still violate self-collision or stability constraints.

Independent forward-kinematics implementations agree over 1,013 validation poses with maximum positional difference $6.8\times10^{-17}$\,m. This near-machine-precision agreement supports the analytical implementation, not mechanical accuracy. The actionable implication is that docking must use a calibrated contact workspace and target pose, rather than a generic visual stopping distance. The wrist envelope provides a reproducible geometric starting point for that calibration.

\subsection{Wheel and Arm Command Semantics}
All 261,121 wheel input pairs match the independent sign partition. Each nonzero sign quadrant contains 65,025 pairs and produces one of four direction commands. Magnitudes within a quadrant are discarded. Exactly one pair, $(0,0)$, emits a stop command; the 1,020 mixed-zero pairs emit no new command. Thus, commanding one stationary wheel and one moving wheel through this branch does not produce the requested wheel pair. No new command must also be distinguished from a stop: the experiment records emitted messages, not subsequent actuator behavior.

This interface behavior directly qualifies Eq.~\ref{eq:drive}. A continuous differential-drive command cannot be assumed to survive a direction-only gateway. Either the upstream controller must deliberately use discrete motion primitives, or the gateway and low-level control must preserve calibrated wheel-rate semantics. This is an integration requirement for controlled approach and docking, not a measured speed error.

The arm mapping matches an independent clamp/reversal specification for all 2,255 evaluated cases. Base commands retain direction, shoulder and elbow conventions are reversed, and the gripper uses its declared command range. These are software command conventions; translating them to the modeled joint angles requires physical calibration. Across geometry, wheel semantics, arm mapping, and schema extraction, all 29 characterization checks pass. The current detector's two named classes confirm the surrogate task configuration; no recognition score is inferred from those labels.
