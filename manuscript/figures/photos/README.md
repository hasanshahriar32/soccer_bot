# Real prototype photograph

The original photographs are photo/bot.jpeg and photo/laptop_front.jpeg at the repository root. They are preserved. manuscript/scripts/annotate_prototype.py generates hazbot_prototype and hazbot_front SVG/PDF/PNG exports with compact numbered vector markers; the original photo pixels are retained.

The paper includes the annotated PDFs through sections/03_prototype_photo.tex. The block prints nothing if that asset is unavailable. Update the source photograph and rerun the figure generator to replace it. Additional source photographs can be stored here, with captions and includegraphics statements added to the optional section.

Describe only components visible in each photograph. A static photograph establishes an assembly, not a complete autonomous trial or hazardous-material validation. Recompile and run the format checker after adding images; six-page and 3 MB limits still apply.
